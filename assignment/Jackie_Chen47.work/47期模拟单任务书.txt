B组项目任务书

项目名称：全国居民收入与消费支出数据分析

一、项目背景
国家统计局“国家数据”平台提供全国、城镇和农村居民的年度收入与消费支出数据。本项目要求获取并整理指定数据，通过计算、比较和 matplotlib 图表分析居民收入、消费结构及城乡差异的变化，最终形成一份有数据、有图表、有结论的分析成果。

数据来源：国家统计局“国家数据”平台
https://data.stats.gov.cn/dg/website/page.html#/pc/national/yearData

数据位置：年度数据 → 人民生活。

二、项目目标
项目完成后，应重点回答以下问题：
1. 近十年居民收入和消费支出发生了怎样的变化？
2. 城镇和农村居民的收入、消费差距是扩大还是缩小？
3. 居民收入主要来自哪些方面，城乡之间有何不同？
4. 居民消费主要花在哪些方面，消费结构发生了怎样的变化？
5. 哪些年份出现了较明显的变化或波动？

数据获取和整理方式自主选择。评价重点是数据是否完整、计算是否正确、图表是否有效、结论是否得到数据支持。

三、数据范围
主分析时间范围统一为 2016—2025 年。

必须获取以下六类数据：
1. 全国居民人均收入情况。
2. 城镇居民人均收入情况。
3. 农村居民人均收入情况。
4. 全国居民人均支出情况。
5. 城镇居民人均支出情况。
6. 农村居民人均支出情况。

部分城乡数据可以追溯到更早年份，可作为扩展分析；主分析必须使用六类数据共同具备的年份，不能使用 0 代替缺失数据。

四、核心任务

任务一：获取并整理数据
1. 获取六类指定数据，并保留一份原始文件。
2. 整理后的数据应能清楚区分：
   - 年份
   - 全国、城镇或农村
   - 收入或支出
   - 指标名称
   - 指标数值
   - 单位
   - 数据来源
3. 统一年份、指标名称、数值和单位格式。
4. 正确处理空值、重复记录和百分比数据。
5. 随机抽取网页数据与本地数据进行核对。

任务二：分析收入与消费趋势
1. 比较全国、城镇和农村人均可支配收入的年度变化。
2. 比较全国、城镇和农村人均消费支出的年度变化。
3. 根据金额计算 2016—2025 年的累计变化和年均复合增长率，并明确这些结果属于名义变化。
4. 比较收入增长与消费增长是否同步。
5. 找出变化较快、较慢或出现明显波动的年份。
6. 官网公布的实际增长率仅作为补充信息，不与根据金额计算的名义增长率混合使用。

任务三：分析城乡差距
1. 计算城镇与农村人均收入的金额差。
2. 计算城镇收入与农村收入的倍数关系。
3. 对城乡消费支出进行相同的比较。
4. 分别观察绝对差距和相对差距的变化。
5. 不能仅依据一个指标就判断城乡差距整体扩大或缩小。

任务四：分析收入来源
1. 比较以下四类收入：
   - 工资性收入
   - 经营净收入
   - 财产净收入
   - 转移净收入
2. 计算各类收入占可支配收入的比例。
3. 找出主要收入来源。
4. 比较全国、城镇和农村收入来源结构的共同点与差异。

任务五：分析消费结构
1. 比较以下消费类别：
   - 食品烟酒
   - 衣着
   - 居住
   - 生活用品及服务
   - 交通通信
   - 教育文化娱乐
   - 医疗保健
   - 其他用品及服务
2. 计算各类消费占人均消费支出的比例。
3. 找出主要消费类别及变化较明显的类别。
4. 比较城镇与农村消费结构的共同点和差异。
5. 可以使用食品烟酒支出占比讨论近似恩格尔系数，但必须说明计算口径。

任务六：分析收支关系
1. 比较人均可支配收入与人均消费支出。
2. 计算全国、城镇和农村的消费倾向，即消费支出占可支配收入的比例。
3. 比较不同居民类型消费倾向的变化。
4. 可以计算收入与消费支出的差额，但不能直接将该差额称为居民储蓄。

任务七：关注特殊年份
1. 重点观察 2020—2023 年人均可支配收入和人均消费支出的变化。
2. 描述数据中出现的下降、反弹或增速变化。
3. 比较全国、城镇和农村居民在特殊年份中的表现。
4. 如果需要解释变化原因，应引用额外证据，不能仅凭数据同时变化就认定因果关系。

任务八：使用 matplotlib 展示分析结果
1. 完成 8 张有效图表。
2. 图表覆盖以下内容：
   - 全国、城镇和农村居民收入趋势
   - 全国、城镇和农村居民消费趋势
   - 城乡收入与消费的绝对差距和相对差距
   - 四类收入来源结构
   - 全国八类消费支出结构变化
   - 最新年度城镇与农村消费结构对比
   - 全国、城镇和农村居民消费倾向
   - 2020—2023 年收入和消费名义同比变化
3. 图表必须有标题、坐标轴名称、单位、图例和数据来源。
4. 年份应按正确顺序排列，金额和比例应使用正确单位。
5. 中文应正常显示，不得出现乱码。
6. 图表应直接服务于分析问题，不为增加数量而制作无意义图表。

五、建议图表
1. 全国、城镇、农村人均可支配收入趋势图。
2. 全国、城镇、农村人均消费支出趋势图。
3. 城乡收入与消费的金额差和倍数变化图。
4. 2016 年与 2025 年四类收入来源占比图。
5. 全国居民八类消费支出占比变化图。
6. 2025 年城镇与农村消费结构对比图。
7. 全国、城镇和农村居民消费倾向变化图。
8. 2020—2023 年收入和消费名义同比变化图。

可以根据分析需要调整图表类型，但最终图表必须能够支撑报告中的主要结论。

六、结论要求
最终报告至少应形成以下几类结论：
1. 收入和消费的总体变化趋势。
2. 城乡收入与消费差距的变化。
3. 主要收入来源及城乡差异。
4. 主要消费类别及消费结构变化。
5. 特殊年份中变化较明显的指标。

结论必须由计算结果或图表支持，并说明以下限制：
1. 人均值不代表每个居民的实际情况。
2. 全国和城乡平均数据不能反映所有地区、家庭或收入群体的差异。
3. 金额上涨不完全等于实际生活水平同比例提高，还应考虑价格变化。
4. 页面给出的实际增长率与根据金额计算的名义增长率不能混为一谈。
5. 描述性年度数据可以说明变化和关联，但通常不能单独证明因果关系。

七、最终成果
1. 原始数据文件。
2. 清洗整理后的数据文件。
3. 核心指标、城乡差距、收入结构和消费结构等分析结果表，以及自动生成的分析摘要。
4. 数据获取、整理、分析和绘图程序。
5. 8 张 matplotlib 图表。
6. 一份完整分析报告，包括：
   - 分析问题
   - 数据来源与范围
   - 数据整理说明
   - 主要计算结果
   - 图表
   - 主要发现
   - 结论限制
7. 项目说明文档，包括运行方法、文件说明和分析口径。


八、验收标准
1. 六类指定数据采集完整，主分析覆盖 2016—2025 年。
2. 原始数据和整理后数据均已保留，字段与单位清楚。
3. 缺失值没有被错误处理成 0，重复记录得到合理处理。
4. 随机抽查至少 3 个数据，与国家统计局页面一致。
5. 城乡差距、结构占比、增长情况和消费倾向等计算正确。
6. 8 张图表能够清楚支撑主要分析结论。
7. 图表、报告正文和统计结果之间不存在明显矛盾。
8. 报告回答了任务书提出的五个核心问题。
9. 对缺失数据、实际增长与名义增长、收支差额与储蓄、相关关系与因果关系作出正确说明。


九、评价建议
项目总分 100 分：
1. 任务完成度：30 分
   是否完成数据获取、整理、计算、绘图和分析报告。
2. 数据质量：20 分
   数据是否真实、完整，缺失值、重复值和单位是否处理合理。
3. 分析与图表质量：25 分
   分析逻辑是否清楚，计算是否正确，图表是否有效支撑结论。
4. 成果表达：15 分
   报告、图表和汇报是否清晰、易于理解。
5. 协作与规范：10 分
   分工是否合理，文件是否齐全，是否注明数据来源并合理访问网站。

十、项目边界
1. 本项目仅用于课程学习和描述性数据分析。
2. 不得绕过登录、验证码或网站安全限制。
3. 不得高频请求目标网站。
4. 不得将分析结果夸大为政策效果或因果证明。
